# PyNexus

PyNexus is the high-fidelity desktop companion app for the PyDaily Ecosystem.

## Setup
1. Fill in `.env` with Supabase keys.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `flet run src/main.py`

## Features
- **The Library:** Read mails and textbooks.
- **The Forge:** Job simulator and coding workspace.
