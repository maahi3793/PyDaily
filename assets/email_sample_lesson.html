Today's Topic

String Formatting & f-Strings

Python's f-strings (formatted string literals) are one of the most elegant ways to embed expressions inside string literals. Introduced in Python 3.6, they make string formatting cleaner and more readable.

Basic Usage

name = "Alice"
age = 25
print(f"Hello, {name}! You are {age} years old.")

Output: Hello, Alice! You are 25 years old.

Expressions Inside f-Strings

You can include any valid Python expression:

price = 49.99
quantity = 3
print(f"Total: ${price * quantity:.2f}")

Output: Total: $149.97

Pro Tips

  • Use :.2f for 2 decimal places
  • Use :, for thousand separators
  • Use :>10 for right-aligned padding
