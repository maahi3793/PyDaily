# Python Practice Workspace 🐍

This folder is your dedicated space to practice Python coding, experiment with snippets, and build small scripts without affecting the main `PyDaily` project.

## How to Use
1.  Create new `.py` files here (e.g., `loops_practice.py`, `calculator.py`).
2.  Run them using your terminal: `python Practice/your_script.py`.

## Example
Check out `playground.py` for a starting point!
